# Style Guide

Este documento define padrões visuais e de interface da plataforma.

Objetivo:

Criar uma experiência **moderna, profissional e intuitiva**.

---

# Filosofia de Design

A interface deve ser:

- limpa
- clara
- rápida
- moderna
- acessível

Inspirado em:

- Linear
- Notion
- Stripe
- LinkedIn

---

# UX Guidelines

Interfaces devem:

- evitar excesso de texto
- priorizar visualização de dados
- minimizar cliques
- ser rápidas

---

# Microinterações

Usar animações suaves.

Exemplo:

hover em cards  
transição de 150ms

---

# Estados de UI

Todos componentes devem ter:

hover  
focus  
disabled  
loading
